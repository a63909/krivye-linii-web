Подключение p2pobmen

Войдите с кодом из почты и подключите бесплатный запуск каждую минуту через cron-job.org.

Откройте ссылку, которую напечатал помощник настройки.

1. Вход в p2pobmen

Пароль и код не попадут в чат. Код используется только для этой попытки входа.

2. Переменные Vercel

Полученная сессия и отдельный токен планировщика будут записаны в production проекта krivye-linii-web.

Для этого компьютера нужен вход через npx vercel@65.15.0 login. После записи выполните redeploy проекта.

3. Внешний планировщик

Ключ создаётся в настройках аккаунта cron-job.org. Планировщик получит только отдельный токен запуска.

Перед включением проверяется готовность сайта без принятия сделок. После включения новые сделки будут обрабатываться автоматически.

Эта форма работает только на вашем компьютере. Секреты сохраняются в закрытом каталоге .p2pobmen-auth, исключённом из Git.
